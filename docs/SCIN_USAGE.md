# SCIN use and attribution

The official SCIN schema, access notebook, README, and Data Use License were reviewed during the data audit. Exact reviewed schema/license blob identifiers are recorded in reports/data_audit.json. Access was verified using the official public GCS distribution.

Project practice:
- Attribute Google Research's SCIN dataset and the Ward et al. paper; link the source and SCIN Data Use License.
- If sharing licensed or adapted material, preserve supplied attribution, copyright, license and warranty notices; indicate modifications and include the license text or link.
- Do not attempt to re-identify or re-link contributors.
- Do not imply official endorsement. Privacy/personality, patent, and trademark rights are not granted by the dataset license.
- Keep images, row-level metadata, manifests, inventory, and private audit details outside this public repository. Public examples require a separate sharing review.
- The MIT license covers original project code; SCIN material remains under its own terms.
